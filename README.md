# 🎉 Happy Birthday

A playful, colourful, fully responsive birthday wishing website built with plain HTML, CSS and JavaScript. Confetti, floating balloons and a "make a wish" button included.

The name shown on the page is set at deploy time through a GitHub Actions workflow.

## 🖥️ Preview locally

Open [index.html](index.html) in a browser. No build step or dependencies.

## 🚀 Deploy

Run the **Deploy birthday site** workflow from the Actions tab and enter a name. Setup steps are in the deployment guide below.
